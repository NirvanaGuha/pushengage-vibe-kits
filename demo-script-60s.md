# 60-second one-prompt demo — script

**Format:** single-take screen recording, no cuts needed. Two windows side by side: Bolt/Lovable left, Claude Desktop right.

| t | Beat | On screen |
|---|---|---|
| 0:00–0:05 | Hook | Title card over the empty builder: **"Push notifications for your vibe-coded app — one prompt, zero SDK reading."** |
| 0:05–0:15 | The prompt | Paste the kit prompt into Bolt/Lovable. Hit go. Speed up the build 4× while narrating: "The prompt carries the exact PushEngage snippet, so the AI can't improvise a broken integration." |
| 0:15–0:25 | App ID | Dashboard → Site Settings → Installation, copy App ID, paste over the placeholder. "One ID. That's the whole config." |
| 0:25–0:35 | Subscribe + trigger | Open the preview in a real tab → Enable notifications → accept → click "Add to cart" and close the tab. |
| 0:35–0:50 | The MCP payoff | Switch to Claude (PushEngage MCP connected). Type: **"Create a cart-abandonment campaign for the cart_abandoned trigger — remind after 30 minutes, then send me a test push now."** Show the tool calls streaming, then the real notification landing on the desktop. |
| 0:50–0:60 | Close | Notification on screen. "Built in Bolt. Campaigns run from Claude. Kit + prompts linked below." End card: `pushengage.com/api/ai-agents` + `npx @pushengage/mcp`. |

**Capture notes:** real UI only (standing rule — no title-card slides inside the demo, cards at 0:00/0:55 only), record at 1080p, keep the notification permission prompt and the OS notification visible — those two moments are the proof.

**Post targets:** X/LinkedIn native video, YouTube Short (crop 9:16 around the two-window layout), embed on the launch-kit LP when it ships.
